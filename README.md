# 侧边栏管理 · dsh-sidebar

用于 DeepSeek Harness 的侧边栏导航管理插件。

## 使用

安装后刷新应用，在 **设置 → 侧边栏管理** 中操作：

- 分别调整主侧边栏功能入口、设置侧边栏页面的排列顺序。
- 使用上下箭头排序，使用开关显示或隐藏项目。
- 本插件的设置入口始终显示，不能隐藏；允许排序。
- 主侧边栏列表中包含「更多」，开关固定开启且不可修改，但可以上下排序。
- 「更多」是收纳分界线：排在上面的菜单直接显示在侧边栏，排在下面的菜单只出现在「更多」菜单中；移回上方即可展开。
- 收入「更多」的菜单保持顺序、点击跳转和当前页面标记；原有的浏览/创建插件等菜单动作保留。
- 支持重置单个列表或恢复全部默认值。
- 排序、显隐和恢复默认均立即生效并自动保存，无需点击应用或刷新；保存失败时显示错误提示。
- 新注册的功能入口会自动出现在列表中，隐藏项目不会停用对应插件。

主侧边栏的「新会话」和底部设置入口保留原有位置，不属于功能入口列表。隐藏的项目既不会显示在侧边栏，也不会进入「更多」。旧配置中的「更多」默认追加在末尾；恢复默认时也回到末尾。

## 保存范围

这些设置只影响导航展示，保存在当前浏览器 / 当前应用来源的 localStorage，键为 `dsh-sidebar.preferences.v1`。刷新或重启后保留；不同来源或浏览器之间不自动同步。同来源窗口通过 storage 事件同步。清理网站数据会清除配置，浏览器存储不可用时页面明确提示保存失败。

## 开发

无需第三方依赖，也不修改 DSH 安装目录或原有插件。

```sh
npm run build
npm test
```

使用 Harness 的插件管理器安装本目录即可。本地目录以链接方式安装，不要删除或移动工作目录。修改客户端代码后重新构建，并刷新应用；是否需要重启取决于插件管理器返回的安装状态。

## 实现与兼容性

针对 DSH `0.2.1-rc.5` 的导航结构实现。该版本没有公开的全局导航过滤接口，且子 Slot 只能由一个注册项声明；旧实现复制父级的子 Slot 声明会引发 `already declared` 错误，现已移除。

当前使用一个版本相关、可撤销的兼容适配层：在原注册项上临时包装组件，投影 `usePanels` / `useSections` 的结果，并按「更多」分界线派生 `useEntryPins`。折叠菜单通过公开的 `sidebar.panellist.actions` 插槽追加，不复制已有子 Slot。针对原应用强制固定「插件」入口的特例，使用仅限展示层的别名并将图标、选中状态和跳转映射回真实 ID。原来的子 Slot 所有权、注入器、语言、存储句柄和动作保持不变。该适配层不是官方稳定扩展接口。

不使用 DOM 查询或改写，不导入 Harness 客户端内部模块，不改写方法原型。卸载时恢复组件引用并清理订阅、事件监听；展示偏好保留以供重新启用。更新客户端代码后须刷新整个应用页面。

此方式依赖原有组件的快照 Hook 名称及可写的组件引用，DSH 更新后若结构改变需重新验证。本插件保护的是自身导航入口，用户仍然可以从插件管理器主动停用或卸载本插件。

## 验证

- 25 项单元测试覆盖默认排序、显隐、入口保护、重排、无效配置、恢复默认、组件适配清理，以及「更多」分界、旧配置迁移、跨分界移动、持久化、插件入口别名和全部折叠/隐藏等情况。
- 构建产物通过 JavaScript 语法检查，资源清单与原创 SVG 图标已检查。
- 插件管理器已返回 `application: applied`，无警告。
- 已通过当前连接页面的 Slot 检查确认 `dsh-sidebar-folded` 与原有 `entry-customization` 菜单项同时处于激活状态，未重复声明应用子 Slot。
- 缺少浏览器交互控制，真实菜单点击、键盘操作、重启保持及深浅主题视觉仍需人工确认；Slot 注册成功不等于完整界面验证。
