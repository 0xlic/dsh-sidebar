# 侧边栏管理 · dsh-sidebar

用于 DeepSeek Harness 的侧边栏导航管理插件。

## 使用

安装后刷新应用，在 **设置 → 侧边栏管理** 中操作：

- 分别调整主侧边栏功能入口、设置侧边栏页面的排列顺序。
- 普通菜单右侧提供「显示」复选框：取消勾选后，从主侧边栏/更多菜单或设置导航中隐藏；管理列表仍保留该项，可随时勾选恢复。隐藏不关闭已打开页面、不停用插件，并与名称、排序一起持久保存。分割项不提供此开关，本插件自身的设置入口保持显示以便恢复其他项目。
- 拖动左侧六点手柄排序，也可聚焦手柄后使用上下方向键。
- 点击菜单名称可直接编辑，无输入框边框或焦点外框，编辑时仅用轻量虚线下划线提示焦点；按 Enter 或离开输入框保存，最多 80 字。修改过的名称后显示小型恢复图标，点击即可恢复插件原名；清空文字也可恢复原名。
- 普通菜单主标题保留插件提供的中文或自定义名称，缺少名称时回退原始英文 ID；小标题统一显示原始英文 ID（底部动作不显示内部偏好前缀），不再显示所在区域或收纳状态。「更多」和「工作区」仍显示分割项说明。
- 主侧边栏列表包含可排序的「更多」和「工作区」分割项，名称固定，不提供显隐开关；两行使用适配深浅主题的灰底，与普通菜单区分，但仍可正常拖动；设置侧边栏不加入这两个分割项。
- 「工作区」代表原生工作区列表的位置：上方菜单显示在工作区上方，下方菜单显示在底部、头像设置上方。可拖动菜单或分割项，也可聚焦拖动手柄后用上下方向键调整。
- 「更多」是收纳分界线：在工作区上方时，收纳其后至「工作区」之前的菜单；拖到工作区下方时，收纳其后的菜单。工作区本身不会收入更多。
- 底部插件动作（例如「工具箱」）同样纳入主侧边栏管理，默认仍在底部，可重命名、移至上方或收入更多。动作继续通过原插件组件执行，不转换成主面板跳转。管理页用统一四宫格表示插件动作；实际侧栏保留插件原图标。
- 收入「更多」的菜单保持顺序、点击跳转和当前页面标记；原有的浏览/创建插件等菜单动作保留。更多菜单统一使用上方侧栏同款 14px 字体、22px 行高、16px 导航图标、6px 图文间距与 12px 左右内边距；图钉保持 14px，插件弹窗内部控件不受这些样式影响。
- 移动设备等以多层函数组件注册的底部动作，同样支持名称同步（可见文字、悬停标题与无障碍名称）；收入更多后会覆盖原按钮的内联行高、负外边距及图文间距，图标保留品牌图案但统一为 16px，不改动动作弹窗或回调。组件实际返回空内容时不生成空菜单行或图钉。
- 「更多」内的原生图钉会将该菜单移到分界线上方，并保存新的顺序；主侧边栏不再显示临时取消固定按钮，避免与持久化分界冲突。
- 名称、排序和分界位置均立即预览，异步保存到插件配置，无需额外点击应用；提供读取中、保存中、只读或失败反馈。保存失败时回退到服务端已确认的配置。
- 没有已保存分界时，「更多」默认位于末尾；已保存排序后，新注册的功能入口追加在后方，因此可能收入「更多」。折叠不会停用对应插件。

**工作区设置 → 工作区一键折叠**（默认开启）：控制「工作区」标题右侧的一键折叠按钮和视图菜单中的折叠项；关闭后两者隐藏或不可用，不影响原生工作区行的展开与折叠。

**工作区设置 → 活跃工作区标识**（默认开启）：工作区下有运行中（包括运行中的子代理）或等待交互的会话时，右侧显示原生会话同款状态圆圈；悬停、键盘聚焦或打开工作区菜单时隐藏，有固定标识时位于其左侧。状态实时更新，工作区折叠不影响标识；已完成但未读的会话不算活跃，会话可见性遵循归档筛选。工作区设置中的活跃工作区标识、置顶工作区、一键折叠和动态调整排序默认均开启；「仅显示固定工作区」筛选仍默认关闭。

**工作区顺序同步到 Host**：DSH 侧边栏打开且当前连接可写时，置顶优先，动态排序仍仅在「按工作区 + 最近更新」时生效。排序规则产生变化时，插件将完整工作区顺序写入 Host 的原生注册表，跟随该注册表顺序的移动端可收到更新。「仅显示固定工作区」是本地筛选，不会删减同步列表；图钉标记仍是插件偏好，不随原生列表下发。关闭功能不回滚已保存的顺序；例如未启用动态排序时，取消最后一个置顶不会自动把该工作区移回旧位置。动态排序按会话最近更新时间计算，已归档会话仍计入；新建会话在发送首条消息前不参与排序，也不会触发 Host 重排。归档、取消归档和切换归档筛选本身都不会改变工作区顺序，也不会触发 Host 重排；多个可写 DSH 窗口的视图规则不同时，Host 以最后完成的写入为准。其他客户端手动调序本身不会触发同一规则再次写入；下次有效排序变化或刷新侧边栏时会重新计算。

侧边栏「工作区」标题右侧操作区最左侧新增 **一键折叠** 按钮（复用原生 chevron 几何与 regular 1px 线宽），与搜索、视图选项、新建工作区组成四个图标：点击一次折叠当前所有工作区（按工作区树时包括父工作区）。按钮只提供折叠，不提供展开；不做禁用或变浅处理，可反复点击，已折叠时再次点击保持折叠状态。按钮不挤占原生搜索、视图选项和新建工作区的操作区；搜索框展开后自动隐藏。

**设置 → 侧边栏管理 → 工作区设置 → 显示批量归档入口**（默认开启）：工作区行的「…」菜单默认显示该项，关闭只隐藏入口，不会恢复已归档的会话。已有安装在更新后请重启一次 DSH 以加载新的设置字段。该菜单项使用与单个会话相同的归档图标，一次归档该工作区直属的未置顶会话，包括未展开显示的会话。已归档会话、空白草稿和其他工作区不受影响；仍有运行中活动的会话不会被自动停止，归档结果会在提示中显示。可在「视图选项 → 仅显示已归档」中找到并恢复已归档会话。

「视图选项」菜单同时提供 **折叠所有工作区** 项，与标题按钮共享同一份原生展开状态；同样只折叠、不展开，也可反复点击。两者都只写入展开状态，不修改工作区注册表、会话或插件配置；单列表模式下按钮和菜单项均不显示或不可用。

侧边栏「视图选项」的「筛选会话」下方新增 **筛选工作区 → 仅显示固定工作区**：勾选后只保留已置顶的工作区及其会话，再次点击即可取消。该筛选仅在「按工作区」分组时生效，切换为「按工作区树」或「单列表」时菜单项显示为不可用且列表保持原样；被隐藏工作区的会话不会以「未分组」形式重现，其展开状态与手动会话顺序也会保留。

主侧边栏的「新会话」和底部头像设置保留原有位置，不属于功能入口排序列表。旧配置中已有的「更多」位置继续保留；新增「工作区」默认位于面板及更多之后，插件动作默认放在其后，因此升级不会主动将工具箱移入更多。普通菜单旧 `hidden` 配置重新作为隐藏偏好读取，但忽略分割项及自身管理入口的隐藏值；旧版 `dsh-sidebar:footer:` 投影配置仍不使用；新动作排序使用独立的 `dsh-sidebar:action:` 偏好标识，不占用真实主面板 ID。

### 右侧文件栏

- 在右侧「文件」列表中右键文件，选择带 **@** 图标的「发送到会话」。文件会作为引用加入当前会话的输入框，保留已有草稿，不会自动发送。仅当文件属于当前会话的工作目录时才提供该操作。
- **设置 → 侧边栏管理 → 右侧边栏 → 发送文件到会话** 默认开启。关闭后隐藏该右键菜单项，不影响已有草稿或隐藏文件设置。
- **设置 → 侧边栏管理 → 右侧边栏 → 显示隐藏文件** 默认开启。打开原生「文件」页时，默认显示以点开头的文件和目录；仍可展开搜索栏，用眼睛按钮单独调整当前工作区。已有的显示选择和插件观察到的手动调整优先于默认值。关闭设置时，插件只在打开「文件」页后撤销本插件为该工作区应用的默认值，不修改用户手动设置。仅打开文件预览不会初始化新工作区的默认值。
- 在右侧 **Markdown 预览**中选中文字，或在 **代码预览**中选中代码（如 JS、TS、Python、Go、Rust、Java），选区旁会显示「引用文本」或「引用代码」。代码引用包含文件路径、源文件行号和所选片段，保留缩进和换行。两种操作都使用原生引用块，保留当前草稿，不会自动发送；纯文本查看器不显示该浮层。
- 在 **设置 → 侧边栏管理 → 右侧边栏** 中，可分别关闭「Markdown 预览引用文本」和「代码预览引用代码」。两项默认开启；关闭不影响选择、复制、会话内引用或已有草稿。
- 这些功能适配 DSH `0.2.2-rc.5` 的原生文件页、预览和会话输入框，无需替换文件树或渲染器。已有安装更新后请重启 DSH 一次，以加载新增的开关配置；之后切换无需重启。

## 保存范围

名称、排序、显隐、更多/工作区分界位置及工作区设置统一保存在 DSH 当前 profile 的本插件 `config.preferences` 中，通过公开的 `configForms` 服务读写。DSH 配置编辑器将变更写入当前 profile 的配置补丁，而不是修改本插件随包发布的配置模板。相同 profile 的其他浏览器也读取这份配置，刷新和重启后保留；不同 profile 仍互相独立。并发修订、写入权限及原子持久化由 DSH settings 服务处理；客户端提交完整 preferences 字段，确保清空名称及重置真正删除旧覆盖。

旧版浏览器配置 `dsh-sidebar.preferences.v1` 仅用于一次性迁移：当服务端没有 preferences、当前连接可写时，将旧名称/排序/显隐写入插件配置；只有服务端确认保存成功后才删除旧本地数据。服务端已有配置（包括显式恢复默认后的空配置）时，不用本地数据覆盖它。浏览器存储不可用不影响新配置的正常保存。

本次显隐升级增加了服务端 `hidden` 配置 schema，已有安装请先重启 DSH 一次，再使用显示开关；只刷新页面不足以加载新的服务端 schema。若管理页提示「插件配置尚不可用」，同样需要重启应用。新 schema 加载后，后续显隐、名称和排序修改均动态保存，无需再次重启。

## 开发

仅依赖 DSH 使用的 `@deepseek-ai/schemastery` 配置 schema 库，不修改 DSH 安装目录或原有插件。

```sh
npm ci --ignore-scripts
npm run build
npm test
```

使用 Harness 的插件管理器安装本目录即可。本地目录以链接方式安装，不要删除或移动工作目录。修改客户端代码后重新构建，并刷新应用；是否需要重启取决于插件管理器返回的安装状态。

## 实现与兼容性

针对 DSH `0.2.2-rc.3` 安装版本的导航源码实现。当前没有公开的全局导航分组接口，因此使用可撤销的版本相关适配层：在原注册项上包装组件，投影 `usePanels` / `useSections` 的顺序与名称；主侧栏保留原生 pin Hook 调用，但忽略其临时状态，按照持久化的「更多」分界派生展示。

侧栏元素树投影移动原生 PanelRow / More，并借用原侧栏拥有者的授权 renderer 按真实 ID 渲染底部动作，不重复声明任何子 Slot，不注册虚构主面板。包括「插件」在内的面板保留真实 ID、图标、选中状态与跳转；原生 More 的浏览/创建插件动作不变。有动作收入更多时，按排序渲染混合菜单，并提供移出更多按钮；固定操作将项目移到更多分界线上方，写入同一份配置。底部动作仅对原标签对应的文本及标题/无障碍名称进行名称投影，原动作回调不变。若无法识别原生 More，保留原始菜单；未知结构下不强行迁移或隐藏底部动作，避免导航无法访问，因此此降级路径不保证底部动作显隐生效。此适配层不是官方稳定扩展接口。

导航适配不依赖 DOM 查询或改写。预览引用适配只在原生 Markdown 正文或代码正文所在的组件内识别浏览器选区，引用由会话原生输入接口插入；不导入预览或会话客户端内部模块。卸载时恢复组件引用并清理订阅、事件监听；展示偏好保留以供重新启用。更新客户端代码后须刷新整个应用页面。

此方式依赖原有组件的快照 Hook 名称及可写的组件引用，DSH 更新后若结构改变需重新验证。本插件保护的是自身导航入口，用户仍然可以从插件管理器主动停用或卸载本插件。

## 验证

- 自动化测试覆盖排序、重命名、工作区设置、旧配置迁移、保存失败回退、更多/工作区分割项首末位置、跨界移动、一键折叠及折叠所有工作区。
- 新增工作区上下布局、工具箱等动作收纳、原始回调与真实插槽 ID 保留、混合更多菜单、动作动态注册/移除，以及空动作不产生幽灵菜单和底部全宽布局的回归测试。
- 主侧栏集成回归验证真实 ID 的「插件」可收入原生 More，当前页面标记、图标/跳转所有权不变，菜单内固定操作持久化、只读和失败反馈，以及分界线的键盘排序。测试使用现有轻量 React/Slot 替身，不代替真实浏览器验证。
- 代码引用测试覆盖文件名解码、源文件行号、缩进与空行、含反引号的片段、无效选区、独立开关和原生预览适配清理。
- 构建产物通过 JavaScript 语法检查，资源清单与原创 SVG 图标已检查。
- 新增配置 schema、名称投影、条件状态控件排除、完整配置写入、旧本地配置迁移、连续编辑、保存失败回退、只读状态及菜单样式回归测试。
- 工作区筛选回归测试覆盖菜单项追加位置与勾选状态、偏好持久化与取消、非「按工作区」分组下的禁用与只读、被隐藏工作区会话不泄漏到「未分组」，以及原生展开状态/手动会话顺序的保留。
- 一键折叠回归测试覆盖设置开关默认开启与持久化、关闭后隐藏标题按钮、标题第四个图标位于搜索左侧、仅折叠不展开、可反复点击且不进入禁用状态、搜索展开时隐藏、工作区树父级折叠、单列表与窄栏降级、无视图写入能力时不显示，以及操作不触碰插件配置。
- 当前本地目录已安装为插件；管理器再次安装返回 `already-installed`，未为强制重装而卸载插件或清除现有配置。本次服务端 schema 升级需重启确认。
- 活跃工作区测试覆盖独立开关持久化、原生 StateDot 复用、状态实时变化、运行中子代理、归档过滤、空白会话排除，以及悬停/聚焦/菜单隐藏样式。
- 已尝试在真实浏览器打开当前 GUI；地址返回认证提示，未能进入页面。真实菜单点击、键盘操作、重启保持及深浅主题视觉仍需确认；自动化测试不等于完整界面验证。
